# Contest standings

Upload DraftKings contest standings files here (the `.zip` DK gives you, or the `.csv` inside it).
Steps are in [docs/SETUP.md](../../docs/SETUP.md#7-upload-dk-contest-results-optional).

- `processed/<game date>/` — files that were matched to a slate, plus a summary for each contest
- `unmatched/` — files that couldn't be used, each with a `.txt` note explaining why
